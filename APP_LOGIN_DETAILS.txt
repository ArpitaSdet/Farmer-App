KISAN KENDRA - Demo App Login Details
=====================================

INSTALL
1. Copy KisanKendra.apk to the phone (WhatsApp / USB / Google Drive).
2. Tap it -> allow "Install unknown apps" when Android asks -> Install.

CONNECT TO THE SERVER (do this once, on the login screen)
Tap "Server: ..." at the bottom of the login screen, type the address, tap Save.

  * Same Wi-Fi as the laptop (laptop must be ON with the server running):
        http://192.168.29.3:5000
  * After hosting on Render:
        https://kisan-kendra-api.onrender.com   (or your Render URL)

TRY THE LIVE FLOW (use 2 phones, or phone + admin panel)
  1. Farmer: add items -> checkout -> place order.
  2. Admin panel: Orders -> Confirm -> Pack (driver gets the job instantly).
  3. Driver: Accept -> Start Trip. Farmer sees the driver live + a 4-digit OTP.
  4. Driver: Arrived -> Complete with the farmer's OTP -> order shows Delivered.
  Rentals: Farmer books a machine -> Owner accepts -> Driver delivers with OTP
           -> Owner taps Start Work -> Work Completed.
