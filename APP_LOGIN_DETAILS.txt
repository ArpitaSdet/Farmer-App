KISAN KENDRA - App Access Details (v1.0.1)
==========================================

INSTALL THE ANDROID APP
1. Copy KisanKendra.apk to the phone (USB / Google Drive / WhatsApp).
2. Open it from Files > Downloads. Allow "Install unknown apps" when asked.
3. Tap Install (if Play Protect warns, tap "Install anyway").
   The app connects to the live server automatically - nothing to configure.

NOTE: The demo server sleeps when unused. If the first screen takes long,
wait ~60 seconds and pull down to refresh.

TRY THE LIVE FLOW (phone + admin panel, or two phones)
  Order:  Farmer places an order
          -> Admin panel: Orders > Confirm > Pack & assign driver
          -> Driver app: Accept > Start Trip  (farmer sees driver + 4-digit OTP)
          -> Driver: Arrived > Complete with farmer's OTP -> Delivered
  Rental: Farmer books a machine -> Owner app: Accept
          -> Driver delivers with the farmer's handover OTP
          -> Owner: Start Field Work > Work Completed
  Everything updates live on all screens - no refresh needed.
